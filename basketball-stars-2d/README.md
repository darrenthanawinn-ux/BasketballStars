# 2D Arcade Basketball Game

A lightweight, single-file 2D arcade basketball web game inspired by *Basketball Stars*, featuring big-head player avatars, side-view court physics, and arcade-style controls. Built using HTML5 Canvas, Tailwind CSS, and vanilla JavaScript.

## Features

* **Arcade Physics:** Gravity-enabled basketball mechanics with smooth floor bounces, backboard rebounds, and rim collision detection.
* **Big-Head Caricature Style:** Stylized player rendering with oversized heads and dynamic movement.
* **Dual Game Modes:** Play 1-player mode against a reactive AI opponent or local 2-player sharing the keyboard.
* **Complete Match Flow:** Interactive start menu, match countdown ("READY? GO!"), 60-second timer, live scoreboard, and game-over screen.

## Controls

| Action | Player 1 | Player 2 / AI |
| :--- | :--- | :--- |
| **Move / Jump** | `W`, `A`, `S`, `D` | Arrow Keys |
| **Shoot / Steal** | `X` | `K` |
| **Special Shot** | `Z` | `L` |

## Quick Start

1. Save the generated code into a single file named `index.html`.
2. Double-click the file to open it in any modern web browser (Chrome, Firefox, Safari, Edge).
3. Click **Quick Match** on the start menu to begin playing!
